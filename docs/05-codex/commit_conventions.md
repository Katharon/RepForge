# Commit Conventions

Use Conventional Commits.

## Types

- `feat`: new user-facing or domain feature.
- `fix`: bug fix.
- `test`: tests only or test infrastructure.
- `docs`: documentation only.
- `refactor`: behavior-preserving code restructuring.
- `chore`: tooling, dependencies, maintenance.
- `ci`: CI/CD workflow changes.
- `build`: build system changes.
- `perf`: performance improvements.

## Scopes

Recommended scopes:

- `repo`
- `docs`
- `architecture`
- `domain`
- `training-log`
- `analytics`
- `timer`
- `notifications`
- `settings`
- `persistence`
- `ui`
- `ci`
- `release`
- `entitlements`
- `sync`

## Examples

```text
feat(domain): add workout set value objects
feat(training-log): implement exercise detail set history
test(analytics): cover one-rep max formulas
ci(flutter): add analyze and test workflow
docs(slices): mark slice 05 complete
```
