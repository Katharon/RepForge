# Use Cases

## Training log

- Create workout group.
- Rename/reorder/archive workout group.
- Add official or custom exercise to group.
- Remove exercise from group without deleting historical sets.
- Create custom exercise.
- Hide/favorite official exercise.
- Log workout set.
- Edit workout set.
- Delete workout set.
- Start training session.
- Finish training session.

## Catalog

- Load bundled catalog manifest.
- Import new catalog version into local database.
- List official exercises.
- Search official and custom exercises.
- Filter by equipment, muscle, movement pattern, favorites, hidden state.
- Apply user override.

## Analytics

- Calculate exercise analytics.
- Calculate group/session analytics.
- Calculate period comparison.
- Calculate estimated 1RM.
- Calculate muscle load.
- Detect potential imbalance.
- Build analytics dashboard cards.

## Training intelligence

- Create/update user profile.
- Generate recommended exercise order for group.
- Suggest alternative exercise.
- Generate quick session.
- Adjust next set recommendation.
- Suggest backoff set or volume adjustment.
- Suggest deload when fatigue is high.
- Explain recommendation reasons.

## Recovery/readiness

- Record post-session exertion.
- Record soreness/DOMS.
- Estimate readiness for workout group.
- Block or warn against high-fatigue recommendations.

## Platform

- Start rest timer.
- Cancel rest timer.
- Schedule local notification.
- Export local backup.
- Import local backup.

## Future

- Estimate calories from anthropometrics.
- Import heart-rate data from wearable/health platform.
- Add friend.
- Show friend activity feed.
- Optional sync account.
- Purchase entitlement.
