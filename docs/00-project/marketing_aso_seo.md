# Marketing, ASO, and SEO

## Principle

RepForge should be designed to be marketable from the start. The app must create moments that look good in screenshots and are easy to explain: fast logging, clean graphs, personal records, workout groups, and later coach-like suggestions.

## App Store Optimization

ASO is the primary discovery discipline for mobile apps.

Planned metadata:

- App name: `RepForge`.
- Subtitle candidate: `Workout Tracker & Progress`.
- English description from MVP start.
- German description from MVP start.
- Keyword sets per locale.
- Localized screenshots for English and German.
- Screenshot sequence: log fast, group workouts, view progress, analyze volume, understand trends.

## SEO

SEO is relevant for external web presence, not inside the native app itself.

Recommended zero-cost path:

1. Static landing page.
2. Localized English/German pages.
3. Public changelog.
4. Privacy policy and terms pages.
5. Blog/articles later, if content marketing becomes useful.

No backend is required for the landing page.

## Product-led growth

Prefer a high-quality free app over aggressive monetization.

The free tier should make users think:

- this is fast,
- this is trustworthy,
- this respects my data,
- this helps me understand training,
- I could use this for months.

Premium should then unlock deeper guidance and reduce thinking effort.

## Review prompts

Do not ask for ratings randomly. Ask only after positive moments, such as:

- user completed multiple workouts,
- user viewed a clear progress improvement,
- user created a useful workout group,
- user used the app consistently for a defined period.

Use platform-compliant prompts and never block usage.
