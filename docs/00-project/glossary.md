# Glossary

## Exercise

A named movement that can receive logged sets, e.g. `Beinpresse sitzend`.

## Workout Set

A performed set for one exercise at one timestamp, with repetitions, weight, optional label, and optional comment.

## Training Session

A group of sets performed in one workout context. A session may be inferred by date/time or explicitly created later.

## Workout Program

A user-defined collection or folder of exercises, e.g. `Unterkörper`, `Push`, `Pull`, `Beine`.

## Rest Timer

A timer started after a set to remind the user when the next set is due.

## Estimated 1RM

Estimated one-repetition maximum. Calculated from repetitions and weight using formulas such as Epley, Brzycki, Lander, O'Conor, or Average.

## Volume

Usually `repetitions * weight`, summed over sets. Unit: kg.

## kg/rep

Average weight per repetition for a period. Usually `totalVolume / totalRepetitions`, if repetitions are greater than zero.

## Label

A set annotation such as `Failure`, `Warm-up`, `Drop set`, or `None`.

## Entitlement

The user's effective right to use a premium capability. Entitlement is not the same as a raw app-store purchase event.

## Local-first

The app's core features work offline and store the canonical workout data locally by default.
