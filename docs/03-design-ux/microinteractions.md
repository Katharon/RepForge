# Microinteractions

## Goals

Microinteractions should make the app feel responsive during workouts without slowing the user down.

## Examples

- Subtle haptic feedback when logging a set.
- Animated rest timer progress.
- Success feedback after saving a set.
- Smooth insertion of a newly logged set into the list.
- Pressed state for large workout buttons.
- Gentle chart point highlight on selection.

## Constraints

- Animations must be short.
- Do not block input.
- Respect reduced motion settings where possible.
- Haptics should be optional in settings.
