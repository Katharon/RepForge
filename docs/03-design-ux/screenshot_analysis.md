# Screenshot Analysis

## What to preserve

- Fast exercise-first logging workflow.
- Dark background and card-based hierarchy.
- Large reps and weight typography.
- Date-grouped set history.
- One-tap add-set access from exercise detail.
- Rest timer visible above current context.
- Lock-screen rest reminder.
- Analytics available from exercise detail.
- 1RM formula configurability.
- Program folders and exercise inclusion workflow.

## What to improve

- More coherent information architecture.
- Better naming consistency between programs, workouts, sessions, and exercises.
- More accessible contrast and touch targets.
- Cleaner charts with empty/sparse states.
- Better first-run onboarding and sample data.
- Better destructive action confirmation.
- Stronger settings structure.
- More explicit privacy and notification settings.

## UI patterns from old app

### Cards

Large rounded charcoal cards separate functional areas. The rebuild should preserve cards but standardize spacing, radius, typography, and interaction states.

### Metric colors

The old app uses green for reps, orange for weight, purple for 1RM, blue/pink for metrics. Keep semantic colors but define them as design tokens.

### Bottom navigation

The old app uses a compact bottom area. The rebuild should use a modern navigation shell with clear primary destinations.

### Floating add button

The floating add button is important during workouts. It should stay reachable and not obscure critical data.

## Important product inference

The old app feels optimized for active workout use, not only post-workout analysis. The rebuild must prioritize speed, one-hand usage, and low cognitive load.
