# Information Architecture

## Primary navigation

Suggested main areas:

1. Today
2. Groups
3. Exercises
4. Analytics
5. Settings

## Today

Purpose: fastest path to action.

Contains:

- recommended next workout/group,
- quick session button,
- readiness summary,
- recent training summary,
- rest timer if active.

## Groups

Purpose: organize training.

Contains:

- Push/Pull/Legs/custom groups,
- exercises assigned to each group,
- start session,
- recommended exercise order,
- group analytics.

## Exercises

Purpose: find and manage exercises.

Contains:

- official bundled exercises,
- custom exercises,
- search/filter by muscle/equipment/movement,
- favorites/hidden,
- exercise detail timeline.

## Analytics

Purpose: understand progress.

Contains:

- metrics matrix,
- charts,
- muscle load,
- imbalance signals,
- 1RM estimates,
- time-window comparisons.

## Settings

Purpose: configure user and app.

Contains:

- profile/focus,
- equipment,
- training frequency/time,
- units,
- theme,
- rest defaults,
- backup/export/import,
- premium later,
- integrations later.

## Legacy screenshot mapping

The old Setgraph exercise detail screen maps to:

- `Exercise Detail`
- `Set Timeline`
- `Rest Timer Banner`
- `Analytics Entry Point`
- `1RM Entry Point`
- `Floating Add Set Button`

The new app should preserve the fast logging feel but improve clarity, recommendation quality, and analytics explanation.
